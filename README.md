🚚 Delivery Post

Это приложение на Spring Boot, реализующее REST API для расчёта стоимости доставки.

📌 Описание

Приложение предоставляет API для расчёта стоимости доставки на основе:

расстояния
веса груза
типа груза
срочности

Включает в себя:

валидацию входных данных
обработку ошибок
документацию API через Swagger
🛠 Используемые технологии
Java 21
Spring Boot
Spring Web MVC
Spring Validation
SpringDoc OpenAPI (Swagger UI)
Lombok
Maven
⚙️ Требования
Java 21+
Maven 3.6+
Docker (опционально)

🚀 Запуск приложения
Через Maven
mvn spring-boot:run

Приложение будет доступно по адресу:

http://localhost:8080

Для удобства запуска приложения используется Docker Compose.

🧠 Архитектурный вопрос
 Что изменить, если тарифы хранить в БД и редактировать через админку?
 

Если тарифы будут храниться в базе данных и редактироваться через административную панель, текущую реализацию 
с захардкоженными коэффициентами в сервисе необходимо изменить. В первую очередь следует вынести тарифы в 
отдельную сущность (например, Tariff), которая будет хранить параметры расчёта: базовую ставку, коэффициенты для 
срочной доставки и надбавки для различных типов груза. Это позволит изменять бизнес-логику без изменения кода и 
повторного деплоя приложения.

Далее необходимо добавить слой доступа к данным (Repository), например с использованием Spring Data JPA, через 
который сервис будет получать актуальные тарифы из базы данных. Сервис расчёта будет использовать эти данные вместо 
фиксированных значений. Для повышения производительности можно добавить кэширование тарифов.

Также можно реализовать административный API для управления тарифами (создание, обновление, удаление). Это сделает 
систему более гибкой и масштабируемой.

Дополнительно, при расширении системы до полноценного сервиса доставки, можно добавить сущность заказа (Order) 
для хранения рассчитанных доставок и их дальнейшей обработки.
